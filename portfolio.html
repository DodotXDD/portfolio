Project 01 · Game assets

Free Barricade Assets Pack

My first assets pack, released for free on itch.io.

View on itch.io →
Task

While browsing the itch.io assets marketplace, I noticed there were almost no barricade assets available. I set out to create a pack to fill that gap for game developers.

Action

I modeled 6 game-ready barricade assets in Blender, textured them, and packaged them as a free starter pack (v1.0).

Result

My first released assets pack is now live on itch.io and free for anyone to use. More packs are planned.

Project 02 · Client website

Soori Bali Website Fix

Client project: fixed the responsive CSS for all screen sizes and the navigation bar on a luxury resort website in Bali.

View website →
Task

A client asked me to fix the website's media queries so it displays properly on every screen size, and to repair the navigation bar.

Action

I rewrote the responsive CSS with breakpoints for phones, tablets and laptops, and fixed the nav bar so it works as a menu on small screens. I tested it on Chrome DevTools and real devices.

Result

The site now displays correctly across all screen sizes and the navigation bar works on every device.
